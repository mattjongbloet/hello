Portfolio Directions

Ten redesigns of Matt Jongbloet’s portfolio, each with a home page, the PMI case study and an about page. All content comes from the current site; copy is tightened, never invented. A–E run from safe to bold; F–J are a second round. Every page passes automated checks at 390, 768, 1024 and 1440px.
